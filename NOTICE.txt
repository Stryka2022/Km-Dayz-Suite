Modification notice (GNU GPL v3 section 5):
Modified by the KM DayZ Suite integration through 28 August 2026 to add an explicit
KM_SUITE_EMBEDDED presentation mode, embedded-process lifecycle behaviour, a
KM-coloured left-rail Server Manager layout, integrated Workshop and Steam sign-in,
integrated Economy tools, FTP/explicit-FTPS remote file management with local
recovery copies, BattlEye RCon, APH Havoc Survival presentation branding, and KM
host-to-companion page navigation. Embedded mode removes the companion's duplicate
navigation rail so KM's main left rail is the single visible Server Manager navigation.
The embedded host and companion resize loops were changed to update only on real size
changes, removing repeated WPF frame invalidation and the white transition surface.
Workshop content was widened for embedded use, and FTP listings now detect and display
Windows or Linux/Unix remote-server platforms. A native Linux x64 headless CLI build is
distributed separately with the same GPL notice and corresponding source; the proprietary
WPF desktop application remains a Windows program. Per-instance Workshop targeting,
automatic Workshop metadata checks, public-key refresh, encrypted per-instance Discord
webhooks, selectable event categories, and throttled server activity/log notifications were
added for KM Suite Server Manager.
Named, independently enabled Discord webhook destinations, encrypted multi-webhook
storage with migration from the earlier single-webhook format, linked per-instance
RCon profiles, persistent Workshop update queues, player-count-aware empty-server
deployment, completed SteamCMD update waits, automatic key refresh, and 15/10/5/1
minute in-game update warnings naming the changed mods were added. Local servers
managed by the active companion instance are stopped and restarted around a due
deployment. Public-facing product names, window titles, setup copy, Workshop labels,
update/source/licence links, CLI descriptions and notifications were rebranded as
APH Havoc Server Manager. The obsolete upstream website button was removed and public
links now target https://github.com/Stryka2022/Km-Dayz-Suite. Server editors and the
setup wizard were converted into inline embedded pages, and new instances gained
friendly display names, unique safe folders, editable collision-free random ports and
optional per-instance DayZ Dedicated Server installs. Those installs now use the chosen
parent path plus the safe server name, require an owned Steam account, verify the actual
DayZServer executable before success, roll back failed instances, detect the LAN IP and
write the server display name into serverDZ.cfg. Windows/Linux platform, CPU,
installed .NET SDK/runtime and .NET 11 detection were added to setup, About and the
headless CLI. Steam QR/password authentication now uses the supported Steam Client
session flow, safely cancels competing attempts, verifies encrypted session persistence,
and the companion executable/windows use the KM DayZ Suite icon. The companion version
for these changes is 0.1.35-km.10.
